# Operations

`ops/` contains operational entry points and project assets.

Command modules parse CLI arguments and call reusable implementation from `app`, `knowledge`, or `infrastructure`.

## Modules

| Module | Responsibility |
| --- | --- |
| [`scripts/`](scripts/README.md) | File upload, chunk writes, recall checks, collection initialization, and document deletion |
| [`docs/`](docs/README.md) | Screenshots and project assets used by documentation |

Run commands from the project root.
